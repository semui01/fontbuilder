      Download & use it

      Name your font, download it, then install it on your computer.

      You'll get a .zip file with your font inside. Open it, then install the .otf file as described below.

      Need it in an email or Google Docs?

      Emails and shared docs only show your font to people who have it installed too. To be sure everyone sees your handwriting (a signature, a thank-you note), use your preview text as a picture:

      Windows
      1. Open the downloaded .otf file and click Install (or right-click it and choose Install).
      2. Restart Word, Outlook or any app that was open. Your font is in the font list under the name you chose.
      Mac
      1. Double-click the downloaded .otf file and click Install Font in Font Book.
      2. It appears in Pages, Keynote, Word, Mail and every other app's font list.
      iPhone & iPad

      iOS only installs fonts through an app. Get a font installer from the App Store, open the .otf with it and follow its steps. Afterwards the font works in Pages, Keynote, Word and other apps that let you pick fonts. For Mail and Messages, use Copy as image instead.

      Android & Chromebook

      These can't install fonts for every app. Apps that accept custom fonts let you import the .otf; everywhere else, use Copy as image.

      Word, Pages & sharing documents

      Pick your font from the font list. Other people only see it if they have it too, so before sending a document either export it as a PDF, or in Word on Windows turn on File → Options → Save → Embed fonts in the file.

      Email (Gmail, Outlook, Apple Mail)

      Desktop Outlook and Apple Mail let you write in any installed font, but recipients who don't have it see a standard font instead. Web Gmail doesn't offer custom fonts at all. For a handwritten signature or note that always looks right, click Copy as image and paste it into your message or signature settings.

      Google Docs & Slides

      Google Docs can't use fonts from your computer. Paste your text as an image (Copy as image), or write in Word, Pages or LibreOffice, where installed fonts work.
